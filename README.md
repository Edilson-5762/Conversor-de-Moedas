## Sobre o projeto

Aplicação front-end que converte valores em Real brasileiro para Dólar americano ou Euro. A cotação de cada moeda é uma constante fixa definida no JavaScript (não consome API externa), e a formatação dos valores é feita com `Intl.NumberFormat`, usando os locais `pt-BR`, `en-US` e `de-DE` conforme a moeda selecionada. A interface troca dinamicamente o ícone e o nome da moeda de destino ao alternar a seleção, e o layout é responsivo, com breakpoints dedicados para tablet e celular.

## Funcionalidades

- Conversão de Real (BRL) para Dólar (USD) ou Euro (EUR)
- Seleção da moeda de destino em dropdown, com troca dinâmica do ícone e do nome exibidos
- Formatação monetária nativa com `Intl.NumberFormat` (pt-BR, en-US, de-DE)
- Layout responsivo com breakpoints em 768px e 480px, incluindo reorientação do fluxo de conversão em telas pequenas
